# Chat: Reglas de Corte

## 1. Propósito

Este documento define cuándo y por qué el Chat corta la conversación.

## 2. Principio rector

El silencio es una respuesta válida del sistema.

## 3. Tipos de corte

El Chat puede cortar por los siguientes motivos:

- Falta de respuesta.
- Respuesta errática o incoherente.
- Abuso (lenguaje, insistencia).
- Volumen excesivo.
- Riesgo operativo.

## 4. Comportamiento ante el corte

Cuando el Chat corta:

- El Chat deja de responder.
- No explica el motivo.
- No ofrece alternativas.
- No redirige.

## 5. Persistencia del corte

La persistencia del corte puede ser temporal o definitiva. La lógica de persistencia pertenece al Core.

## 6. Relación con otras capas

El corte mantiene las siguientes relaciones:

- Catálogo: no influye.
- Core: define reglas y duración.
- Edge: no participa.

## 7. Métricas internas permitidas

El Chat puede medir internamente:

- Ratio de corte.
- Motivo agregado (no individual).
- Tiempo hasta corte.

## 8. Prohibiciones explícitas

El Chat está prohibido de realizar las siguientes acciones ante un corte:

- No mensajes de advertencia.
- No contadores.
- No avisos de bloqueo.
- No feedback al usuario.

## 9. Frase canónica de cierre

Cuando el sistema corta, no explica. Simplemente deja de estar.
