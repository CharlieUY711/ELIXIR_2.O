# NECTAR — Modelo Interno

## 1. Propósito de Nectar

Nectar es la señal interna de control y balance del sistema ELIXIR. Su función es regular el consumo de recursos y mantener el equilibrio operativo mediante mecanismos de autorización y ajuste contextual.

## 2. Qué es Nectar

Nectar es una unidad interna de medida que opera exclusivamente dentro del Core de ELIXIR. Es una abstracción técnica que no tiene representación visible para usuarios finales ni para las capas externas del sistema.

Nectar existe únicamente en la lógica de negocio del Core. No tiene valor de cambio ni reconocimiento fuera del sistema. No puede utilizarse para transacciones comerciales. No aparece en balances, estados de cuenta ni interfaces de usuario.

## 3. Qué NO es Nectar

Nectar no es un activo, un instrumento financiero ni un bien transable. Específicamente:

Nectar no se compra. No existe mecanismo de adquisición externa.

Nectar no se vende. No existe mecanismo de venta o liquidación.

Nectar no se transfiere. No puede moverse entre usuarios, cuentas o entidades.

Nectar no se muestra al usuario. No tiene representación en ninguna interfaz.

## 4. Cómo se usa

El Core consume Nectar para autorizar acciones dentro del sistema. El consumo se ajusta dinámicamente según el contexto operativo, la carga del sistema y las condiciones de riesgo.

Cada operación que requiere autorización del Core implica un consumo de Nectar según reglas internas. El volumen de Nectar consumido varía según factores como tipo de operación, estado del sistema, historial del usuario y condiciones de mercado.

## 5. Qué representa

Nectar codifica información operativa y de riesgo en una única señal:

Nectar refleja el costo computacional y de recursos de una operación. Incorpora la evaluación de riesgo asociada a la acción. Indica la prioridad relativa de la operación en el contexto del sistema. Refleja el estado de carga y capacidad del sistema en el momento de la operación.

## 6. Relación con capas

Nectar es exclusivo del Core y no debe ser conocido ni referenciado por otras capas:

El Catálogo no conoce Nectar. Opera sin conocimiento de su existencia.

El Chat no menciona Nectar. No debe aparecer en conversaciones ni respuestas.

El Edge no expone Nectar. No transmite información sobre Nectar a sistemas externos.

El Core es la única capa que gestiona Nectar. Es responsable de su cálculo, consumo y ajuste.

## 7. Prohibiciones explícitas

Queda estrictamente prohibido:

Nectar no debe aparecer en ninguna interfaz de usuario, pantalla, mensaje o notificación.

No existen balances de Nectar que puedan consultarse o mostrarse.

No se establecen equivalencias entre Nectar y monedas, puntos, créditos u otros sistemas de valor externos.

## 8. Frase canónica

Nectar existe para equilibrar el sistema, no para ser visto.
