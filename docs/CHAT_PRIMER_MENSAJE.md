# Chat: Primer Mensaje

## 1. Propósito del primer mensaje

El primer mensaje abre la conversación sin explicar el sistema. Marca presencia sin prometer resultado.

## 2. Qué comunica

El primer mensaje comunica:

- Existencia de interlocución.
- Disponibilidad de continuar la conversación.

## 3. Qué NO comunica

El primer mensaje no comunica:

- Precios.
- Disponibilidad específica.
- Reglas.
- Duración.
- Identidad del servicio.
- Próximos pasos.

## 4. Forma

El primer mensaje debe ser:

- Mensaje corto.
- Lenguaje adulto.
- Neutro.
- Sin signos de exclamación.
- Sin emojis.
- Sin marketing.

## 5. Longitud

El primer mensaje tiene:

- Máximo una línea.
- Idealmente una palabra o saludo mínimo.

## 6. Relación con el flujo

El primer mensaje:

- Habilita el núcleo de preguntas.
- No decide.
- No deriva.
- No corta.

## 7. Prohibiciones explícitas

El primer mensaje está prohibido de contener:

- No "bienvenida".
- No "gracias por escribir".
- No "te conectamos".
- No "estás hablando con".

## 8. Frase canónica de cierre

El primer mensaje abre. No explica. No promete.
