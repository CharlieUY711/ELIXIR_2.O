ETAPA 1 — PRODUCTO VIVO SIN DINERO
(DÍAS 1–30)
--------------------------------

Las duraciones son orientativas.
Cada bloque puede extenderse, pausarse o detener la etapa completa.
No constituyen compromisos de calendario.

Bloque 1 — Base operativa mínima
Estimación de duración: 5–7 días

Bloque 2 — Chat p2p controlado
Estimación de duración: 4–6 días

Bloque 3 — Media mínima y visibilidad
Estimación de duración: 3–4 días

Bloque 4 — Uso real curado
Estimación de duración: 5–7 días

Bloque 5 — Observación y cierre
Estimación de duración: 2–3 días

Objetivo:
- Validar uso real sin monetización

Permitido:
- Registro
- Verificación WhatsApp
- Edad delegada
- Chat p2p enmascarado
- Uso con personas reales curadas
- Observación pasiva
- Kill-switch activo

Prohibido:
- Cobros
- Promesas
- Marketing
- Optimización
- Escala
- Almacenamiento innecesario

Criterio de cierre:
- Estabilidad técnica
- Cero incidentes de custodia
- Uso real observado

ETAPA 2 — OPERACIÓN + PRESENCIA VISUAL PASIVA
(DÍAS 31–60)
--------------------------------

Carril Producto:
Objetivo:
- Introducir monetización controlada

Permitido:
- Gate de pago
- Cobro delegado
- Habilitación de cobro para modelos

Prohibido:
- Promociones
- Descuentos
- Automatizaciones complejas

Carril Marca (pasivo):
Objetivo:
- Generar familiaridad visual

Permitido:
- Mostrar nombre
- Mostrar logo
- Usar identidad visual

Prohibido:
- Explicar el producto
- CTA
- Mensajes comerciales
- Contenido explícito

ETAPA 3 — PRODUCTO COMPLETO + EXPECTATIVA ÉTICA
(DÍAS 61–90)
--------------------------------

Objetivo:
- Preparar lanzamiento público responsable

Permitido:

- Campaña de expectativa ética (editorial)

Prohibido:
- Hype
- Ads masivos
- Influencers
- Promesas comerciales
