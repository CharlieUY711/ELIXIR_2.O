# WhatsApp Edge

## Rol

Borde controlado hacia WhatsApp.

## Responsabilidades

- Derivación mediante handoff tokens
- Validación de tokens y estados
- Auditoría de eventos (no contenido)

## Características

- Acceso temporal, un solo uso, revocable
- TTL corto (~5 minutos)
- Rate limiting y prevención de loops

## Estado

Implementación pendiente.
