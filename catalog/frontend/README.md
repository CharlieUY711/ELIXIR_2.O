# Frontend - Catálogo Elixir (Maqueta)

## Descripción

Maqueta visual del Catálogo Elixir basada en el diseño de Figma. Renderizado local para visualización.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

La aplicación se abrirá automáticamente en `http://localhost:3000`

## Estructura

- `/src/pages/Catalog.tsx` - Componente principal del catálogo
- `/src/pages/Catalog.css` - Estilos del catálogo
- `/src/App.tsx` - Componente raíz
- `/src/main.tsx` - Punto de entrada

## Notas

- Esta es una maqueta visual aislada
- No incluye integración con Core, WhatsApp ni Twilio
- Los CTAs son placeholders no funcionales
- Los estados (idle/loading/error) son simulados
