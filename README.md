# Elixir Platform

Plataforma modular de control de valor y orquestación transaccional.

## Capas

1. **Catálogo**: Capa visual de conversión
2. **Chat**: Orquestación transaccional
3. **Elixir Core**: Núcleo de control y autorización
4. **Borde WhatsApp**: Puerta de salida controlada hacia WhatsApp
